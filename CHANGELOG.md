this file. Per-package changelogs are also generated by Changesets at release
time and live alongside each package's `package.json`.

architectural decisions, and tech-debt closures that span more than one
package. For machine-readable per-package history, see each
`packages/*/CHANGELOG.md`.

## [0.1.0] - F4 Round 1 (initial public release)

### Added

- **Topic-pattern matcher hoisted to core (`@llm-feedback-middleware/core`).**
  New `matchesTopic` helper plus a vitest suite. In-memory and Redis pub/sub
  adapters now share a single matcher implementation. (Closes tech-debt **D1**.)
- **`SubscribeOptions` are now validated.** Adapters declare a
  `SubscribeCapabilities` object listing supported `deliveryMode` and
  `fromPosition` values, and `subscribe()` throws a descriptive error when an
  unsupported option is requested. Both the in-memory and Redis pub/sub
  adapters declare `at-most-once` + `latest` only. (Closes tech-debt **D5**.)
- **`>` wildcard documented in the framework spec.** §9.2.1 now covers `*` and
  `>` semantics explicitly, and notes the shared `matchesTopic` source of
  truth. (Closes tech-debt **D6**.)
- **`SECURITY.md`** with private vulnerability-reporting instructions via
  GitHub Security Advisories or email. (Closes tech-debt **L2**.)
- **Top-level `CHANGELOG.md`** (this file) aggregating cross-package history.
  (Closes tech-debt **L1**.)
- **`CODE_OF_CONDUCT.md`** (Contributor Covenant 2.1) and **`CLA.md`**
  (individual + corporate templates) for inbound contributions.
- **GitHub issue templates** (bug report, feature request) and a pull-request
  template under `.github/`.
- **GitHub Actions release workflow (`.github/workflows/release.yml`)** that
  runs Changesets on merge to `main` and opens a release PR.
- **Per-package READMEs expanded.** `core` and `adapter-conformance` now
  document install, public API surface, the conformance contract, and how
  consumers wire them in. (Closes tech-debt **L3**.)
- **JSON-Schema artifact (`schemas/feedback-event.schema.json`)** generated
  from the Zod source of truth via `schemas/generate.ts`. The protobuf form
  (`schemas/feedback-event.proto`) is included for non-Node consumers.

### Changed

- **Outbox `markFailed` now uses `make_interval`** for the retry-delay
  computation (`make_interval(secs => $3::float8 / 1000.0)`) instead of the
  earlier string-concatenation form (`($3::int || ' milliseconds')::interval`).
  Behavior is identical; the new form is type-safe and reads as
  parameterized. (Closes tech-debt **N1**.)
- **Examples (`postgres-only`, `postgres-redis`) wrap their main flow in
  `try/finally`** so the Postgres pool, Redis bus, outbox scanner, and
  subscriber unsubscribe even when capture throws. (Closes tech-debt **L7**.)

### Notes

- Phase F3 already closed **H1, H2, H3, H4, D3, M1, M2, M3** (see prior
  Development_Logs.md and TECH-DEBT.md history).
- 8 tech-debt items remain open: **H5** (deferred until Kafka/Streams
  adapter), **M4, M5, M6, D2, D4, L4, L5, L6**, plus **N2**. These are
  scheduled for the F4 Round 2 release. The full list is tracked in
  [`TECH-DEBT.md`](./TECH-DEBT.md).

## [0.0.0] - Phase F0 through F3 (pre-publish)

The framework was incubated inside the BEPA repository under
`Part 2 of research/A02-Building-a-Learning-Loop-Every-LLM-Output-as-Training-Signal/feedback-middleware/`.
Phase deliverables shipped behind feature flags or as code-only changes
without npm release. The relevant entries live in:

- `IMPLEMENTATION-PLAN.md` §6, §7, §8, §8.5, §8.6, §9.
- `Development_Logs.md` entries dated `2026-04-23` through `2026-04-24`.

Highlights:

- F0: monorepo scaffold, core types, in-memory adapters.
- F1: Postgres event store, projection store, conformance suites.
- F2: Redis pub/sub bus, transactional outbox, middleware pipeline,
  inference engine.
- F2.5: middleware unit tests, OutboxPort + InferenceRulesPort conformance,
  in-memory outbox adapter.
- F2.6: observability + scaling (`onPublishError`, subscriber `onError`,
  `readStreamSince`, advisory-lock leader election).
- F3: streams package (RxJS-based), reference projections + capture
  adapters, edit-diff labeler, schema upcasters.
